Counts phrases in the exhaustive Lempel–Ziv 1976 parsing of a byte sequence.

LZ76 measures how many production steps are needed to build a sequence by
copying earlier material and adding a new byte. It detects sequential structure
that byte frequencies discard. The result is an exact integer **phrase count**
for the supplied finite sample, not a bit length or a source-entropy estimate.

## Short history

Abraham Lempel and Jacob Ziv introduced this individual-sequence complexity in
1976 in [On the Complexity of Finite Sequences](https://doi.org/10.1109/TIT.1976.1055501).
Their exhaustive history attains the minimum number of production steps.
The [parsing exposition by Mills (2003)](https://mro.massey.ac.nz/bitstreams/1ecf0b74-226c-4826-b381-18413c506f64/download)
states the reproduction/production distinction and the final-component exception.
LZ77 and LZ78 are different constructions; this API specifically implements LZ76.

## Definition and operation

Let `x` contain `N` bytes. At a phrase start `p` (zero-based), let `r=N-p` and

```text
M(p) = max({0} union { k : 0 <= j < p, 0 <= k <= r,
                          x[j..j+k] = x[p..p+k] })
phrase_length(p) = min(M(p) + 1, r)
c_76(x) = number of phrases obtained, starting at p=0
```

`j` is an earlier copy-source position; `k` is a matching length in bytes.
`max` chooses the longest reproducible prefix; a phrase adds one byte beyond it
unless the sample ends first. Advance `p` by that phrase length and repeat.
The implementation handles the end separately, avoiding unnecessary arithmetic.

Copies **may overlap the current phrase**. At offset `t`, `j+t < p+t`, so a
copied byte always comes from material already produced. Search includes all
earlier starting positions, including those inside earlier phrases, not just a
dictionary of completed phrases. Equivalently, each nonfinal phrase `x[p..e]`
is the shortest nonempty block absent from `x[..e-1]`. The final remaining suffix
counts once even if it is reproducible. There is no sentinel, wraparound, text
decoding, fixed window, alphabet parameter, or normalization.

## Worked examples and edge cases

`ABABAB` parses as `A | B | ABAB`. The first two bytes need separate productions;
the suffix copies from position zero, overlapping itself, and contributes one
final phrase. Thus `c_76=3` phrases. `AAAA` gives `A | AAA`, hence 2; restricting
copies to the completed prefix would give a different parsing.

Empty input returns 0, one byte returns 1, and any constant input of length at
least two returns 2. For `N>0`, `1 <= c_76(x) <= N`; for `N>=2`, the lower bound
is 2. All-distinct bytes give `N` phrases. An exact phrase boundary at the end
does not add an empty final phrase.

```
use celandine::complexity::lz76_complexity;
assert_eq!(lz76_complexity(b""), 0);
assert_eq!(lz76_complexity(b"A"), 1);
assert_eq!(lz76_complexity(b"AAAA"), 2);
assert_eq!(lz76_complexity(b"ABABAB"), 3);
assert_eq!(lz76_complexity(b"ABCD"), 4);
assert_eq!(lz76_complexity(b"101101011"), 5); // 1 | 0 | 11 | 010 | 11
```

## Algorithm, units, and cost

The scalar implementation scans earlier source positions, extending each match
by byte comparisons. It uses `O(1)` auxiliary space and **no heap allocations**.
Worst-case time is `O(N^2)`: for a phrase of length `ell`, at most `N` sources
each examine at most `ell` bytes, and phrase lengths sum to `N`. It stops early
when a source reproduces the entire remaining suffix. Constant and short-period
inputs can therefore be much cheaper than high-diversity inputs. Large arbitrary
inputs may be slow; no linear-time suffix index is claimed.

The output uses `usize` and is bounded by input length. Index additions stay
within the slice. There are no floating-point calculations, tolerances, or
invalid parameter errors. The function neither mutates nor retains the input.

## Interpretation and limits

Bijective byte renaming preserves the count; reversal and arbitrary reordering
need not. Raw counts depend on sample length. They do not give compressed size,
Kolmogorov complexity, randomness certification, or an exact entropy rate of an
unknown source. No normalization or asymptotic inference is performed.
[Estevez-Rams et al. (2013)](https://arxiv.org/abs/1311.0546) discuss why high
finite LZ76 counts do not establish randomness. Compare subword complexity,
which counts distinct blocks at a fixed length rather than production phrases.
