Empirical quantities ≠ source guarantees

Frequency-based metrics describe the observed law. LZ and compressor scores do not certify randomness or compute true Kolmogorov complexity.

Context support is only partial

Order-based conditional entropy uses context counts internally. A general public context transform or conditional-distribution API is still missing.

Coverage has practical limits

Linux x86-64 is the tested runtime baseline. Diverse-input LZ parsing remains quadratic; high-order profiles can be costly.
